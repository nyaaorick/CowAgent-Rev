## [Naming & State-Control Rules]

### Python

1. **File header** — `# encoding:utf-8` on line 1, then a module docstring.
2. **Docstrings explain *why*, not *what*.** A docstring that only restates the signature is noise here. State the invariant, the failure mode, or the upstream defect being worked around. Cite `ROADMAP WCF-BUG-0N` when the reason is an upstream defect.
3. **Import order** — stdlib, blank line, third-party (`web`, `wcferry`), blank line, first-party (`bridge.*`, `channel.*`, `common.*`, `config`, `models.*`). First-party imports are one flat block, not sub-grouped.
4. **Declaration order in a file** — imports → module constants → private helpers → public functions → classes.
5. **Naming** — module-private helpers and constants take a leading `_` (`_LOCAL_HOSTS`, `_spy_log_path`, `_require_auth`). Public config-facing constants do not (`ALL_CONTACT`, `FILEHELPER_ID`).
6. **Security-relevant defaults fail closed.** An empty or malformed whitelist means *nobody*, never *everybody*. A malformed input narrows a gate; it never widens one. Say so in the docstring.
7. **Logging** — `from common.log import logger`, messages tagged with the component: `logger.error(f"[WebChannel] Workspace read error: {e}")`, `logger.info(f"[WcfChannel] ...")`.
8. **Language** — comments, docstrings, log messages and identifiers are English (ROADMAP directive 7). Chinese appears **only** where it is the product itself: persona prompts, WeChat-facing reply text, user-typed commands (`#清除记忆`), `I18N.zh` values, and regexes matching Chinese model output.

### web.py handlers

9. **Route registration** — the `urls` tuple at [`web_channel.py:1859`](CowAgent/channel/web/web_channel.py#L1859) maps a path to a handler **class-name string**, resolved by `web.application(urls, globals())` against `web_channel.py`'s namespace. A handler defined elsewhere must therefore be imported into `web_channel.py` for the route to resolve.
10. **New route groups ship as their own module** under `channel/web/` (e.g. `contacts_api.py`), and `web_channel.py` gains only the `import` line and the `urls` entries. *(Decided 2026-09-07; existing handlers stay where they are — this is not a mandate to break up the current file.)*
11. **Handler body order** — `_require_auth()` → `web.header('Content-Type', 'application/json; charset=utf-8')` → `try:` → parse (`web.input(...)` for GET, `json.loads(web.data() or b'{}')` for POST) → validate required fields, returning `{"status": "error", "message": "<field> is required"}` → do the work → `json.dumps({"status": "success", ...}, ensure_ascii=False)`.
12. **Error envelope** — never raise out of a handler. Catch specific exceptions (`ValueError`, `FileNotFoundError`) plainly, then a bare `except Exception as e:` that logs *and* returns the error envelope. A machine-readable variant adds a `"code"` field (see `conflict` in `WorkspaceWriteHandler`).
13. **`ensure_ascii=False`** on any `json.dumps` whose payload can contain Chinese (contact names always can).

### Frontend (vanilla JS, no framework)

14. **New console feature = new file** under `static/js/`, loaded with `<script defer>` at the bottom of `chat.html` after `console.js`. It reuses `console.js` globals rather than re-implementing them, and says so in its banner comment.
15. **Module prefix on every global** — `workspace.js` owns `WS_*` constants and `ws*` state. A new module picks its own prefix and never introduces an unprefixed global.
16. **One `async` API gateway per module**, modelled on `wsApi()`: build the URL, `await fetch`, `await res.json()`, `if (data.status !== 'success') throw new Error(data.message || 'Request failed')`.
17. **All user-visible text goes through i18n** — add the key to **both** `I18N.zh` and `I18N.en` in `console.js`, then use `t('key')` in JS or `data-i18n="key"` in HTML. Dynamic re-render on language switch goes through `rerenderDynamicViews()`.
18. **Navigation** — a new view needs three edits in lockstep: a `VIEW_META` entry ([`console.js:1687`](CowAgent/channel/web/static/js/console.js#L1687)), a `.sidebar-item[data-view]` anchor in the menu group, and a `<div id="view-<id>" class="view">` section. `navigateTo()` drives breadcrumbs off `VIEW_META`, so a missing entry silently no-ops.
19. **Styling is Tailwind utilities inline** in `chat.html`, with `dark:` variants on every colour. Only genuinely reusable component classes go to `static/css/console.css`. `darkMode: 'class'`.
20. **Vendored assets only.** Everything third-party is served from `static/vendor/` — no CDN `<script src>` may be added.
21. **Comment the non-obvious state, not the obvious.** The codebase comments *why* a flag exists (`wsAutoOpenSuppressed`, `wsEditBaseMtime`); it does not narrate `let x = 0`.

### Tests

22. `CowAgent/tests/` is the pytest root (`testpaths = ["tests"]`), files named `test_<subject>.py`, shared fixtures in `conftest.py` / `support_*.py`. Tests hitting a real GLM endpoint are marked `@pytest.mark.live` and are deselected by default.

## [DONTs]

- **DO NOT edit `cowagent2/`.** It is a read-only reference tree for this work. Port *from* it by copying and adapting into `CowAgent/`; never modify the source.
- **DO NOT edit `WeChatFerry/`** as part of console/agent work — it is vendored upstream with its own repair track in ROADMAP.
- **DO NOT introduce a framework or build step** into the console. No React/Vue/JSX, no bundler, no `npm install`, no ES modules — the page loads plain `<script defer>` files.
- **DO NOT add a CDN link.** Vendor it under `static/vendor/` and note the source in `static/vendor/README.md`.
- **DO NOT hardcode user-visible strings** in JS or HTML. A literal that reaches the screen without an `I18N` key is a defect.
- **DO NOT let a whitelist or permission default to permissive.** Empty, missing, or malformed → deny. `""` must never be spelled as "allow all"; that is what the explicit `ALL_CONTACT` sentinel is for.
- **DO NOT swallow an exception silently.** Log with the `[Component]` tag *and* return the error envelope.
- **DO NOT put tests in `CowAgent/test/`** — despite the name it holds operator scripts and config samples (`check_config.py`, `run.cmd`, logos), and pytest does not collect it.
- **DO NOT write new tooling code with Chinese comments** (see rule 8), and do not translate the Chinese that is product text.
- **DO NOT copy defects out of a Golden File.** Reuse the structure; if the exemplar has a bug, flag it rather than propagating it.
- **DO NOT bolt new feature state onto `console.js`.** Nav registration and `I18N` keys belong there; the feature's own state and rendering belong in its own prefixed module.
